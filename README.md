## About

I'm a computer science graduate specializing in database administration, with a background in software and mobile development. This portfolio highlights my projects, achievements, and how to get in touch as I look to kickstart my career in IT.

## Features

- **Home** – A quick introduction and overview
- **Projects & Achievements** – A showcase of things I've built and accomplished
- **Contact** – Ways to reach me, including email, phone, and LinkedIn

## Built With

- [Jekyll](https://jekyllrb.com/) / GitHub Pages
- HTML, SCSS, Liquid templating

## Getting Started

To run this project locally:

```bash
git clone https://github.com/your-username/repo-name.git

bundle install

```

Then open `http://localhost:4000` in your browser.
